TP A FAIRE SUR LES 4 SwITCH

ACTIVER SSH - Desactiver TELNET
Seul le reseau 192.168.99.0/24 PEUT MANAGER LES EQUIPEMENTS
Creer un utilisateur => Admin:Reponse2025
domaine =  examen.labo
cle ssh : 2048 bits


Pre-requis 
verifier ios de cisco ... vous devez trouver K9 dans le nom (show version)
il doit y avoir un mot de passe enable
le switch doit avoir une adresse ip


en
conf t
!!Définir le domaine
ip domain-name examen.labo

!!Création de la clé SSH
crypto key generate rsa general-keys modulus 2048 
!!Activation de ssh v2
ip ssh version 2


!! creation du compte admin
aaa new-model
aaa authentication login default local
aaa authorization exec default local
username Admin secret Reponse2025

!!Creer un acl pour le reseau autorisé
access-list 22 permit 192.168.99.0 0.0.0.255


!!active ssh (donc desactiver)
line vty 0 15
login local
transport input ssh
!!Applique l'acl 22
access-class 22 in

Tester à faire

-Connection TELNET vers switch à partir du pc portable => PAS OK
-Connection ssh vers switch à partir du pc DU VLAN 10 => PAS OK
-PING entre Pc Portable et un serveur => OK

Pre-requis 
verifier ios de cisco ... vous devez trouver K9 dans le nom (show version)
il doit y avoir un mot de passe enable
le switch doit avoir une adresse ip

1)si mon sw est un MDP ou no, si il n'y a pas un mdp, donc ssh ne fonction pas
2)verifier si os est compatible 
show veersion
nom image=sw image===>K9 pour que le sw compatible a ssh
3)do show run (si sw est un ip)
!!par example 
!!creation ip pour valan 99
en
conf t
interface vlan 99
ip address 192.168.99.21 255.255.255.0
no shutdown

!!creation de mdp SW
en 
conf t
enable secret (mdp)


en
conf t
!!Définir le domaine
ip domain-name examen.labo

!!Création de la clé SSH
crypto key generate rsa general-keys modulus 2048
!!Activation de ssh v2
ip ssh version 2


!! creation du compte admin ssh
aaa new-model
aaa authentication login default local
aaa authorization exec default local
username Admin secret Reponse2025

!!Creer un acl pour le reseau autorisé
access-list 22 permit 192.168.99.0 0.0.0.255


!!active ssh (donc desactiver telnet)
line vty 0 15
login local
transport input ssh
!!Applique l'acl 22
access-class 22 in

!!SSH

!!Passe en mode privilégié
enable                                              

!!Passe en mode configuration globale
conf t                                              

!!Définit le mot de passe du mode privilégié
enable secret cisco                                   

!!Définit le nom de domaine (obligatoire pour SSH)
ip domain-name tssr.greta                         

!!Génère les clés RSA (2048 bits)
crypto key generate rsa general-keys modulus 2048   

!!Force l'utilisation de SSH v2 (sécurisé)
ip ssh version 2                                    

!!Active le modèle AAA
aaa new-model                                       

!!Authentification via la base locale
aaa authentication login default local              

!!Autorisation d'accès au mode EXEC
aaa authorization exec default local                

!!Crée un utilisateur local avec mot de passe chiffré
username azy secret cisco                   

!!Autorise uniquement le réseau 192.168.4.0/24 dan vlan 417 ip vlan 192.168.4.17/24
access-list 22 permit 192.168.4.0 0.0.0.255        

!!Configure toutes les lignes VTY (accès distant)
line vty 0 15                                       

!!Utilise la base locale pour l'authentification
login local                                         

!!Autorise uniquement SSH (désactive TELNET)
transport input ssh                                 

!!Applique l'ACL sur les connexions entrantes
access-class 22 in                                  

!!Quitte le mode configuration
end                                                 

!!Sauvegarde la configuration
write memory

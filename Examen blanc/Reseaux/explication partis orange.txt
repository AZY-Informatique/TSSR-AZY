# 🧩 1. روتر 1841

## ❌ حذف Loopback

دستور تو:

```
no int l0
```

🔴 اشتباهه

✅ درستش:

```
conf t
no interface loopback0
```

👉 باید اسم کامل اینترفیس نوشته بشه.

---

## 🌐 گرفتن IP از DHCP

```
int fa0/1
no shut
ip address dhcp
```

### ✔️ معنی:

* اینترفیس **FastEthernet0/1** روشن میشه (`no shut`)
* به جای IP دستی، از DHCP درخواست IP می‌کنه

📌 یعنی:
روتر 1841 مثل یک کلاینت عمل می‌کنه و از روتر Orange IP می‌گیره

---

# 🌐 2. روتر 2911 (Orange)

```
hostname Orange
```

👉 فقط اسم روتر رو تغییر میده

---

## 🧱 اینترفیس‌ها

### G0/0 (شبکه داخلی)

```
int g0/0
ip address 50.50.50.50 255.0.0.0
no shut
```

👉 اینجا DHCP به کلاینت‌ها IP میده

---

### G0/1 و G0/2

```
int G0/1
ip address 142.251.255.254 255.255.0.0
no shutdown

int G0/2
ip address 8.255.255.254 255.0.0.0
no shutdown
```

👉 این‌ها معمولاً نقش اتصال به شبکه‌های دیگه یا اینترنت رو دارن

⚠️ نکته:
این IPها واقعی (Public) هستن — برای تمرین بهتره Private باشه

# 📡 3. DHCP روی Orange

```
ip DHCP pool POOL_Orange
network 50.0.0.0 255.0.0.0
default-router 50.50.50.50
dns-server 8.8.8.8
```

## ✔️ عملکرد:

* به کلاینت‌ها IP از رنج `50.x.x.x` میده
* Gateway = `50.50.50.50`
* DNS = 8.8.8.8

---

## ⚠️ نکته مهم (خیلی مهم)

باید IP روتر رو exclude کنی:

```
ip dhcp excluded-address 50.50.50.50
```

💥 وگرنه ممکنه DHCP این IP رو بده به کلاینت → مشکل شبکه

# 🔍 4. دیدن وضعیت اینترفیس

```
show ip int fa0/1
```

## ✔️ چی نشون میده:

* آیا اینترفیس روشنه یا نه
* IP گرفته یا نه
* وضعیت line protocol
* NAT / ACL (اگر باشه)

# 🔄 کل سناریو به زبان ساده

3. Orange بهش IP میده
4. ارتباط بین دو روتر برقرار میشه
